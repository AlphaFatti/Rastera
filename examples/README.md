# Canvas editor demo

Synthetic RGBA checker (transparent, partial-alpha and opaque cells) plus editable text. Both boxes cross the 1920-pixel output seam. No external media is required.

```sh
cargo run --release --locked -p rastera-desktop --bin canvas-editor -- --project=examples/canvas-demo.rastera.json
```

The image was generated by the same procedural fixture pattern as `tools/canvas_editor_probe.py`. Text and geometry came from the direct native UI workflow test; the media reference is relative to this project. These are real editable objects, not baked screenshots. The diagnostic background supplies animation for continuity observation. Selection handles appear only after selecting a layer in the operator.

## Nested viewport selection regression

```sh
cargo run --release --locked -p rastera-desktop --bin canvas-editor -- --project=examples/nested-viewports.rastera.json
```

This media-free schema-2 fixture places the larger Right footprint around Left. Choose **Viewports**, select Right in the sidebar, then drag Left's name or outline. Right must stay put. Undo, try moving Right, and Option-click their shared area to cycle selection. Both clean windows show the diagnostic canvas through their own mappings.

`dynamic-viewports.rastera.json` is a self-contained schema-4 diagnostic composition with seven named output proportions. Run `cargo run --release --locked -p rastera-desktop --bin canvas-editor -- --project=examples/dynamic-viewports.rastera.json --outputs=4`. Open additional windows independently in Viewports mode.
