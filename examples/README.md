# Canvas editor demo

Synthetic RGBA checker (transparent, partial-alpha and opaque cells) plus editable text. Both boxes cross the 1920-pixel output seam. No external media is required.

```sh
cargo run --release --locked -p rastera-desktop --bin canvas-editor -- --project=examples/canvas-demo.rastera.json
```

The image was generated by the same procedural fixture pattern as `tools/canvas_editor_probe.py`. Text and geometry came from the direct native UI workflow test; the media reference is relative to this project. These are real editable objects, not baked screenshots. The diagnostic background supplies animation for continuity observation. Selection handles appear only after selecting a layer in the operator.
